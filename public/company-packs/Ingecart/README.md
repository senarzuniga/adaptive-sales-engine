# Ingecart Company Data Folder

This folder stores the structured Ingecart dataset used by the application.

## Source
- Extracted company pack: `seeds/ingecart_pack.json`

## Structure
- `ingecart_pack.json`: full import/export pack accepted by the app
- `company_profile.json`: normalized company profile
- `orders.*`: historical orders
- `opportunities.*`: current pipeline opportunities
- `products.*`: product/service catalog
- `strategy.*`: strategic planning entries
- `tasks.*`: proactive execution tasks for agent cascades
- `ingecart_pack.json.workspace.*`: company-scoped workspace seeds (contacts, offers, reports, marketing content, after-sales assets, spare parts, rates, and more)

## Usage
1. Open **Saved Companies**.
2. Click **Load Ingecart Pack** (or import `ingecart_pack.json` manually).
3. Open Ingecart from the company selector.
4. Review the loaded company across Data Upload, Offer & Pricing, Monitoring, Business Intelligence, Marketing Content, After-Sales, and Team Directory.

# Readiness Integration Report

El Orchestrator integra con el ASE Readiness Engine (ARE) publicando eventos en el Event Capture Layer. ARE calcula el ARS leyendo los eventos append-only.

La ejecución del Orchestrator genera métricas de ejecución (duraciones, confianza de agentes, uso de conocimiento, cumplimiento de gobernanza) que ARE usa para ajustar la puntuación.
